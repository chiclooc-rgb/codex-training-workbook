# 직원 자율학습형 코덱스 교재 삽입자료 촬영목록

작성일: 2026-05-21  
수정일: 2026-05-23  
용도: 교재 본문에 넣을 화면 캡처, 예시 파일, 결과물 이미지 수집 가이드

## 1. 전체 원칙

교재 이미지는 기능 소개용 화면보다 "직원이 따라 하는 장면"을 보여주는 것이 좋다.

좋은 캡처는 다음 조건을 만족한다.

- 화면에 사용자가 따라 할 문장이 보인다.
- 결과물이 어떻게 생기는지 보인다.
- 실패하거나 수정하는 장면도 일부 포함한다.
- 실제 개인정보, 내부 시스템 계정, 비공개 문서는 보이지 않는다.
- 파일 경로는 가능하면 샘플 폴더를 사용한다.
- PPTX나 문서 서식을 보여줄 때는 원본 내용보다 레이아웃, 폰트, 여백, 줄바꿈 규칙이 보이게 찍는다.

## 15. 촬영 시 주의사항

- 내부 시스템 URL, 계정명, 개인정보는 가린다.
- App Secret, Access Token, 장기 토큰, Redirect URI, 서버 환경변수는 반드시 가린다.
- 실무 예시는 가능하면 가짜 데이터로 재현한다.
- 화면을 너무 넓게 찍기보다, 사용자가 봐야 할 부분 중심으로 자른다.
- 결과물 화면은 폰트 크기를 키운 뒤 찍는다.
- 이미지 파일명은 장 번호를 붙인다. 예: `08-04_designmd_스타일규칙.png`

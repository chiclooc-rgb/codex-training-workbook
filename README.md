# Codex Training Workbook

직원 자율학습형 Codex 교재 원고를 관리하는 저장소입니다.

교재 본문은 루트의 `00_...md`부터 `10_...md`까지 장별 파일로 관리합니다.

실습자료는 루트의 `실습자료_02_...`, `실습자료_03_...` 폴더에 둡니다.

## 폴더 구조

- 루트의 `00_...md` ~ `10_...md`: 계속 개선해 나가는 최신 교재 원고
- `2026-05-23_수업초안`: 2026년 5월 23일 스터디 당시 기준 초안 스냅샷
- `DESIGN_md_스터디_QA_정리_20260524.md`: 수업 중 나온 `design.md` 질문 보강 자료

수업 당시 자료는 `2026-05-23_수업초안`에 고정 보관하고, 이후 수정은 루트의 장별 파일에 반영합니다.

## 운영 원칙

- 공개 가능한 교육자료와 비식별 샘플만 올립니다.
- 실제 업무자료, 개인정보, 내부 검토자료는 올리지 않습니다.
- Access Token, App Secret, 비밀번호, `.env`는 올리지 않습니다.
- 수정 이력은 Git 커밋으로 관리합니다.

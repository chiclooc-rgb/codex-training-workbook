# Codex Training Workbook

직원 자율학습형 Codex 교재를 GitHub와 Notion에서 함께 관리하기 위한 공유 저장소입니다.

## 용도

- 교재 Markdown 원고 보관
- Notion에 올릴 초안과 배포본 정리
- 삽입 이미지, 캡처 목록, 실습자료 관리
- 수정 이력과 버전 비교

## 폴더 구조

```text
docs/
  교재 본문과 목차, 촬영목록
notion/
  Notion 업로드용 정리본 또는 내보내기 파일
assets/
  교재에 넣을 이미지, 캡처, 샘플 자료
```

## 운영 원칙

- 공개 가능한 교육자료와 비식별 샘플만 올립니다.
- 실제 업무자료, 개인정보, 내부 검토자료, 계정 토큰, App Secret은 올리지 않습니다.
- `.env`는 로컬에서만 사용하고, 공유가 필요하면 `.env.example`만 올립니다.
- Notion에 올릴 문서는 `notion/`에 따로 정리합니다.

## 현재 상태

초기 구성용 저장소입니다. `docs/`에는 현재 작성 중인 직원 자율학습형 Codex 교재 초안이 들어갑니다.

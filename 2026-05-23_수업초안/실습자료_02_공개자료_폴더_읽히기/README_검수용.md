# 02장 실습자료 검수용

용도: `02. 공개자료 폴더 읽히기` 장에서 사용할 샘플 폴더입니다.

이 폴더의 파일은 모두 교육용 가짜 자료입니다. 실제 개인정보, 내부자료, 계약자료는 들어 있지 않습니다.

다만 실습 효과를 위해 실제 업무폴더처럼 파일명을 일부러 어지럽게 만들었습니다. `최종`, `최최종`, `진짜최종`, `final`, `수정본`, `구버전`, `확인필요`, `열람보류`가 섞여 있습니다. 직원들은 Codex에게 바로 파일 내용을 읽히지 말고, 먼저 파일명과 확장자 기준으로 공개 가능 여부와 최신 후보를 분류하게 해야 합니다.

## 직원에게 시킬 첫 말 예시

```text
이 폴더를 바로 읽어도 되는지 모르겠어.
파일 내용은 아직 열지 말고, 파일 목록만 보고 공개자료인지 확인해줘.
파일명 기준으로 공개 가능, 확인필요, 열람보류 후보를 나눠줘.
```

## 검수 포인트

- 파일 내용을 열기 전에 목록부터 확인하게 되는가
- `최종`, `최최종`, `진짜최종`, `final` 파일이 여러 개일 때 최신 후보를 추정하되 확정하지 않는가
- `확인필요`, `열람보류` 후보를 임의로 열지 않게 하는가
- 파일명 기준 추정과 실제 확인 사실을 구분하는가
- 최종 결과물로 파일 인벤토리 표를 만들 수 있는가

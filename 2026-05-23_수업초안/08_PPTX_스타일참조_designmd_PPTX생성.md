# 08. 기존 PPTX를 읽혀 `design.md` 만들고 새 PPTX 생성하기

## 이 장에서 만들 결과물

이 장에서는 기존 PPTX의 스타일을 분석해 `design.md`로 정리하고, 그 규칙을 바탕으로 새 PPTX 초안을 만듭니다.

최종 결과물은 다음입니다.

- `design.md`: 색상, 폰트, 레이아웃, 문장 규칙을 정리한 디자인 문서
- `샘플_교육자료.pptx`: `design.md`를 바탕으로 만든 새 PPTX
- `PPTX_검수메모.md`: 폰트, 여백, 줄바꿈, 민감정보 여부 검수 기록

이 장의 목표는 PPTX를 예쁘게 꾸미는 것이 아닙니다.

> 기존 PPTX를 감으로 따라 하지 않고,  
> 스타일을 규칙으로 뽑아낸 뒤  
> 새 자료에 재사용하는 방법을 익히는 것입니다.

여기서도 핵심은 완성형 프롬프트가 아닙니다. 처음부터 색상, 폰트, 여백을 모두 알고 말할 필요는 없습니다. 오히려 이렇게 시작합니다.

```text
이 PPTX의 스타일을 참고해서 새 자료를 만들고 싶어.
네가 스타일을 분석하려면 어떤 점을 봐야 해?
표지, 도비라, 본문을 나눠서 먼저 분석 관점을 제안해줘.
```

Codex가 분석 관점을 제안하면, 사용자가 "폰트가 중요하다", "한국어 어절 줄바꿈을 꼭 봐야 한다", "하단 여백이 과하면 안 된다"처럼 기준을 보태는 방식으로 `design.md`를 만듭니다.

## 먼저 알아야 할 것

PPTX 스타일을 참고한다는 것은 내용을 복사하는 일이 아닙니다.

참고해야 할 것은 다음입니다.

- 표지 슬라이드 구조
- 도비라, 즉 장을 나누는 구분 슬라이드 구조
- 본문 슬라이드의 제목 위치
- 본문 텍스트 박스 위치
- 이미지와 설명 문장의 배치
- 색상 팔레트
- 폰트와 굵기
- 강조색
- 여백
- 한국어 줄바꿈 방식

복사하면 안 되는 것은 다음입니다.

- 원본 PPTX의 내부 내용
- 저작권 표시가 필요한 이미지
- 기관 내부자료
- 개인정보
- 발표자 메모나 숨김 슬라이드의 민감 내용

## 준비물

실습 폴더를 만듭니다.

```text
codex-public-practice
└─ 08_PPTX_스타일참조
   ├─ 00_reference
   ├─ 01_working
   └─ 02_output
```

`00_reference` 폴더에 참고할 PPTX를 넣습니다.

직원 실습에서는 공개 가능한 PPTX만 사용합니다. 내부 교육자료를 쓰더라도 외부 배포가 가능한 범위인지 먼저 확인해야 합니다.

이 장의 예시 주제는 다음입니다.

```text
새로 만들 PPTX 주제: 디스코드 화면공유 방법
분량: 4쪽
대상: 사내 직원
목표: 화면공유를 처음 하는 사람도 따라 할 수 있게 안내
```

## 1단계: 바로 PPTX를 만들지 말고 스타일만 분석하기

처음부터 "이 스타일로 PPTX 만들어줘"라고 하면 결과가 흔들립니다. 먼저 스타일 분석 관점을 Codex와 함께 정하고, 그 다음 분석만 시켜야 합니다.

```text
`00_reference` 폴더에 있는 PPTX는 서식 참고용입니다.

내용을 그대로 복사하지 말고,
스타일만 분석해서 `01_working/design.md`로 정리해주세요.

분석할 항목:
- 전체 톤과 용도
- 표지 슬라이드 레이아웃
- 도비라 슬라이드 레이아웃
- 본문 슬라이드 레이아웃
- 제목 위치와 크기
- 본문 위치와 하단 여백
- 이미지 또는 캡처 배치 방식
- 색상 팔레트
- 폰트 이름과 굵기 체계
- 강조색 사용 방식
- 한국어 문장 줄바꿈 규칙

주의:
- 원본 내용을 그대로 옮기지 마세요.
- 저작권 표시, 기관명, 내부 문구는 새 PPTX 규칙에 포함하지 마세요.
- 새 자료에 재사용 가능한 규칙만 정리해주세요.
```

## 2단계: `design.md`에 꼭 들어가야 할 내용

`design.md`가 잘 만들어졌는지 확인합니다.

좋은 `design.md`에는 최소한 아래 내용이 있어야 합니다.

```markdown
# 디자인 규칙

## 1. 전체 톤
- 교육용 실습자료
- 짧고 직접적인 문장
- 파란색 상단 바와 흰 본문 영역

## 2. 슬라이드 유형
- 표지
- 도비라
- 본문
- 요약

## 3. 색상
- 메인 블루: #...
- 강조 노랑: #...
- 본문 글자: #...

## 4. 폰트
- 제목: A2Z 또는 Paperlogy 계열 Bold
- 본문: A2Z 또는 Paperlogy 계열 Regular
- 캡션: 같은 계열 Light

## 5. 한국어 줄바꿈
- 같은 어절 안에서 줄바꿈 금지
- 숫자와 단위는 가능하면 붙여서 유지
- 짧은 문장 중심

## 6. 본문 레이아웃
- 제목은 상단 바 안에 배치
- 본문은 너무 위에 붙이지 않음
- 하단 여백이 과하게 남지 않도록 본문 블록을 아래로 조정
```

내용이 부족하면 "어떤 정보가 부족한지"를 먼저 묻고, 이렇게 다시 보강하게 합니다.

```text
`design.md`가 아직 추상적입니다.
다른 사람이 이 문서만 보고 PPTX를 만들 수 있게
색상값, 폰트 계열, 슬라이드별 레이아웃, 여백 기준, 한국어 줄바꿈 규칙을 더 구체적으로 보강해주세요.
```

## 3단계: 새 PPTX의 구성안 만들기

이제 새 PPTX를 만들기 전에 구성안을 정합니다.

```text
`01_working/design.md`를 참고해서
"디스코드 화면공유 방법" 교육자료 4쪽 구성안을 만들어주세요.

슬라이드 구성:
1. 표지
2. 도비라: 화면공유 시작하기
3. 본문: 서버 또는 음성채널에서 화면공유 시작
4. 본문: 공유 화면 선택과 주의사항

각 슬라이드마다 다음을 적어주세요.
- 슬라이드 제목
- 핵심 문장
- 들어갈 화면 캡처 설명
- 발표자가 말할 포인트
- 한국어 줄바꿈 주의 문장

아직 PPTX 파일은 만들지 말고 구성안만 `01_working/PPTX_구성안.md`로 작성해주세요.
```

캡처가 없어도 괜찮습니다. 캡처 자리에 들어갈 설명을 텍스트로 충분히 써 두면 됩니다.

예:

```text
캡처 자리: 디스코드 음성채널 하단의 화면공유 버튼 위치를 보여주는 이미지
대체 텍스트: 화면공유 버튼은 음성채널에 입장한 뒤 하단 조작 영역에서 찾을 수 있습니다.
```

## 4단계: 새 PPTX 만들기

구성안이 정리되면 PPTX를 생성합니다.

```text
`01_working/design.md`와 `01_working/PPTX_구성안.md`를 기준으로
`02_output/디스코드_화면공유_방법.pptx`를 만들어주세요.

생성 기준:
- 원본 PPTX 내용은 복사하지 마세요.
- copyright 표시는 넣지 마세요.
- 폰트는 A2Z체 계열을 우선 사용하고, 없으면 Paperlogy 계열로 대체해주세요.
- 제목과 본문 굵기 체계는 design.md 기준을 따르세요.
- 같은 어절 안에서 한국어 줄바꿈이 생기지 않게 해주세요.
- 본문 위치는 너무 위에 붙이지 말고, 하단 여백이 과하게 남지 않게 조정해주세요.
- 캡처가 없는 슬라이드는 캡처 자리 설명을 임시 박스로 넣어주세요.
```

PPTX 생성이 어려운 환경이면 먼저 HTML 또는 Markdown 시안으로 만들고, 이후 PPTX로 옮길 수 있습니다.

```text
현재 환경에서 PPTX 생성이 어렵다면
같은 내용으로 슬라이드별 Markdown 시안을 먼저 만들어주세요.
각 슬라이드의 제목, 본문, 캡처 자리, 디자인 지시를 분리해서 적어주세요.
```

## 5단계: 폰트 확인하기

PPTX에서 폰트는 매우 중요합니다. 폰트가 바뀌면 같은 레이아웃도 완전히 다르게 보입니다.

Codex에게 폰트 검수를 시킵니다.

```text
생성한 PPTX의 폰트 적용 상태를 검수해주세요.

확인할 것:
- 제목 폰트
- 본문 폰트
- 캡션 폰트
- 굵기 체계
- 대체 폰트가 섞였는지 여부

검수 결과는 `02_output/PPTX_검수메모.md`에 정리해주세요.
```

직접 PowerPoint를 열 수 있다면 다음도 확인합니다.

1. 슬라이드를 클릭합니다.
2. 제목 텍스트를 선택합니다.
3. 홈 탭의 폰트 이름을 봅니다.
4. 본문 텍스트도 같은 방식으로 확인합니다.
5. PC에 폰트가 없으면 다른 폰트로 대체될 수 있습니다.

## 6단계: 한국어 줄바꿈 확인하기

한국어 PPT에서 중요한 것은 같은 어절 안에서 줄이 갈라지지 않는 것입니다.

나쁜 예:

```text
화면공유를 시
작합니다
```

좋은 예:

```text
화면공유를
시작합니다
```

또는 더 좋은 예:

```text
화면공유를 시작합니다
```

줄바꿈 검수도 Codex에게 먼저 확인 관점을 말하게 할 수 있습니다.

```text
PPTX의 모든 슬라이드 문장을 검토해서
같은 어절 안에서 줄바꿈이 생길 가능성이 있는 문장을 찾아주세요.

수정 기준:
- 긴 문장은 짧은 문장으로 나눕니다.
- 한 줄에 억지로 많이 넣지 않습니다.
- 숫자와 단위, 버튼명은 가능하면 붙여 둡니다.
- 줄바꿈이 필요한 경우 어절 단위로 끊습니다.

수정이 필요하면 PPTX를 다시 고쳐주세요.
```

## 7단계: 여백과 본문 위치 확인하기

본문이 너무 위에 붙거나 아래 여백이 너무 많으면 슬라이드가 비어 보입니다.

검수 대화 예시:

```text
PPTX의 본문 위치와 하단 여백을 검수해주세요.

확인 기준:
- 본문이 상단 제목바에 너무 붙어 있지 않은가
- 하단 여백이 과하게 남지 않는가
- 캡처와 설명 문장이 균형 있게 배치되어 있는가
- 슬라이드마다 본문 시작 위치가 일관적인가

필요하면 본문 블록을 조금 아래로 내리고,
캡처 자리와 설명 문장의 크기를 조정해주세요.
```

## 8단계: 최종 검수표 만들기

```text
최종 PPTX 검수표를 만들어주세요.

검수 항목:
1. 원본 PPTX 내용을 그대로 복사하지 않았는가
2. copyright 표시를 제거했는가
3. 폰트가 지정한 계열로 적용됐는가
4. 한국어 어절 중간 줄바꿈이 없는가
5. 본문 위치와 하단 여백이 적절한가
6. 표지, 도비라, 본문 슬라이드가 구분되는가
7. 캡처가 없는 부분은 임시 박스나 설명으로 표시했는가
8. 민감정보나 내부자료가 들어가지 않았는가

결과는 `02_output/PPTX_검수메모.md`에 표로 저장해주세요.
```

## 혼자 해보는 과제

아래 중 하나를 골라 같은 방식으로 만들어 봅니다.

- "회의록을 할 일 목록으로 바꾸는 방법" 4쪽 PPTX
- "공개자료 폴더를 Codex에 읽히는 방법" 4쪽 PPTX
- "민원답변 누락검토 실습" 5쪽 PPTX
- "HTML 보고서 만드는 방법" 4쪽 PPTX

## 오늘 배운 절차

1. 참조 PPTX를 준비한다.
2. 바로 새 PPTX를 만들지 않고 `design.md`를 먼저 만든다.
3. 새 PPTX 구성안을 만든다.
4. `design.md`와 구성안을 기준으로 PPTX를 생성한다.
5. 폰트, 줄바꿈, 여백, 민감정보를 검수한다.

```text
PPTX 스타일을 재사용할 때는
원본 내용을 복사하지 않고 디자인 규칙만 `design.md`로 추출한다.
표지, 도비라, 본문 레이아웃을 분리하고,
색상, 폰트, 여백, 한국어 줄바꿈 규칙을 명시한다.

```

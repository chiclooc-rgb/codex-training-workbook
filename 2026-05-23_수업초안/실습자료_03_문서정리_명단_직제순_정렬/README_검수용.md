# 03장 실습자료 검수용

용도: `03. 문서 정리하기: 교육대상자 명단 직제순 정렬` 장에서 사용할 샘플 폴더입니다.

이 폴더의 명단은 모두 가짜 데이터입니다. 연락처, 생년월일, 주소, 실제 사번은 넣지 않았습니다.

## 직원에게 시킬 첫 말 예시

```text
교육대상자 명단을 직제순으로 정리하고 싶은데,
정확히 하려면 어떤 기준이 필요한지 먼저 물어봐줘.
내가 기준을 고르면 그다음 정리하자.
```

## 실습 목표

- `직제순_기준표.csv`를 기준으로 부서 순서를 정한다.
- 같은 부서 안에서는 팀명 가나다순, 같은 팀 안에서는 성명 가나다순으로 정리한다.
- 기준표에 없는 부서는 삭제하지 않고 맨 아래 `확인필요`로 남긴다.
- 정렬 후 연번은 새로 부여한다.
- 원본 인원 수와 정리 후 인원 수가 같은지 확인한다.
